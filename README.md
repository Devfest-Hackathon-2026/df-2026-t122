# 📱 neck-app

**動画を楽しみながら、姿勢を意識する。**

neck-appは、スマートフォンやPCでの長時間の動画視聴によって生じる「スマホ首（テキストネック）」に着目した、姿勢改善支援Webアプリケーションです。

MediaPipeによるリアルタイムの姿勢・瞬き検知と、スマートフォンの傾き検知を活用し、動画視聴中に姿勢への気づきを促します。

さらに、姿勢維持時間の記録やポイント機能を組み合わせることで、日常的な動画視聴を健康習慣づくりのきっかけに変えることを目指しています。

**🌐 公開URL（Firebase Hosting）**

https://resolve-teck-neck.web.app/

## 🎯 解決したい課題

### 背景

スマートフォンやPCが日常生活に欠かせない一方、長時間の動画視聴中に無意識のうちに首を前に突き出したり、下を向いた姿勢を続けたりすることがあります。

このような姿勢は首や肩への負担につながる可能性がありますが、動画に集中していると自分の姿勢の崩れに気づきにくいという課題があります。

### 対象ユーザー

- スマートフォンやPCで長時間動画を視聴する学生・若者
- 動画視聴中に姿勢が崩れやすい人
- 健康習慣を身につけたいが、継続することが難しい人

### 解決へのアプローチ

neck-appでは、動画視聴と姿勢検知を一つのWebアプリケーションに統合しています。

姿勢の崩れや一定時間瞬きが検出されない状態を検知すると、動画を停止することなく、映像の明るさ・彩度の変化や警告アイコンによって利用者に知らせます。

また、姿勢維持時間の記録やポイントの獲得によって、姿勢を意識する行動を継続する動機づけを行います。

設計には行動変容フレームワーク「COM-Bモデル」を取り入れ、姿勢に気づく機会（Opportunity）と、継続する動機（Motivation）の両面からアプローチしています。

## ✨ 主な機能

### 1. 📷 カメラによる姿勢検知

MediaPipe Poseを利用し、カメラ映像から顔や肩の位置関係を解析して姿勢の崩れを推定します。

- ブラウザ内でリアルタイムに姿勢を推定
- 顔や肩のランドマークを利用
- 姿勢の判定結果を警告表示に反映
- カメラ映像はサーバーに保存せず、端末内で解析

### 2. 📱 スマートフォンの傾き検知

DeviceOrientation APIを利用し、端末の前後・左右の傾きから画面の向きを表す角度を算出します。

- 前後方向の `beta` と左右方向の `gamma` を使用
- 両方の値を組み合わせた角度計算
- 算出角度が40度未満、または130度超の場合に警告
- 初回セットアップ時のセンサー確認にも利用

カメラによる姿勢推定とは別の検知方法として、スマートフォン利用時の姿勢への気づきを支援します。

※ ブラウザや端末によってセンサーの取得可否が異なります。縦持ち・横持ちなどの環境での判定精度は、今後の実機検証が必要です。

### 3. 👁 瞬き検知

MediaPipe FaceMeshを利用して目の開閉を判定し、動画視聴中の瞬き回数を計測します。

- 目の開閉状態をリアルタイムに判定
- 瞬き回数を記録
- 約10秒間瞬きが検出されない場合に注意を促す
- 姿勢警告と同様に映像の変化による通知に対応

### 4. ⚠️ 動画を停止しない警告表示

姿勢の崩れや瞬きに関する警告が発生した場合、動画を停止せず、視覚的な変化によって注意を促します。

**通常表示**
- 赤い通知バナー
- 映像の明るさ・彩度の低下
- 右上の警告アイコン

**全画面表示**
- 映像の明るさ・彩度の低下
- 右上の警告アイコン
- 通知バナーは非表示

警告が解除されると、映像は通常の明るさ・彩度に戻ります。

### 5. ▶️ YouTube動画検索・再生

YouTube Data API v3を利用し、アプリ内で動画を検索・表示できます。

- 動画検索
- 動画の埋め込み再生
- 人気動画などの表示
- 検索履歴・視聴履歴に関する機能
- 独自の全画面表示

全画面表示では、ブラウザのFullscreen APIを利用します。APIが利用できない場合や処理に失敗した場合は、CSSによる疑似全画面表示へ切り替える構成です。

全画面表示中も姿勢や瞬きに関する警告を表示できるよう、動画プレイヤーと警告表示を同じ領域内に配置しています。

### 6. 📺 登録チャンネル連携

GoogleアカウントによるYouTube連携を通じて、登録チャンネルの情報を取得・表示します。

普段視聴しているチャンネルの動画をneck-app内で楽しめるようにする機能です。

※ 現在、YouTube連携はOAuthのテストユーザーに限定されています。Firebase Authenticationによるアプリへのログインとは別の認可処理を使用します。

### 7. 📊 姿勢・瞬きログの自動記録と可視化

計測したデータをCloud Firestoreに保存し、ユーザーごとに管理します。

主な記録対象：
- 姿勢維持時間
- 瞬き回数
- カメラ計測時間
- ポイント

保存したデータは記録画面で取得し、日別の集計やグラフで確認できます。

※ YouTube動画の実際の視聴時間や視聴本数を正確に計測する機能は、現時点では実装していません。

### 8. 🏆 ゲーミフィケーション

姿勢維持に応じてポイントを獲得できる仕組みを実装しています。

姿勢を意識する行動に達成感を加え、継続的な利用につなげることを目指しています。

### 9. 🔐 Googleログイン・初回セットアップ

Firebase AuthenticationによるGoogleログインに対応しています。

また、初回利用時には以下の設定を案内します。

- Googleログイン
- カメラの利用
- スマートフォンの傾きセンサー

各設定は必要に応じてスキップでき、利用環境に合わせてアプリを使用できます。

### Google技術の活用

本プロジェクトでは、Googleの技術を以下のように活用しています。

**MediaPipe**

カメラ映像をブラウザ内で解析し、専用のAI推論サーバーを用意せずに姿勢・瞬きの検知を実現しています。

**Firebase Authentication**

Googleアカウントを利用したユーザー認証を実装しています。

**Cloud Firestore**

姿勢維持時間や瞬き回数などの計測結果をユーザーごとに保存・取得しています。

**Firebase Hosting**

React・TypeScriptで構築したWebアプリをHTTPS環境で公開しています。

**YouTube Data API v3**

動画検索や動画情報の取得を行い、動画視聴と姿勢検知を一体化しています。

## 🏗 システム構成

neck-appは、React・TypeScriptによるフロントエンドを中心としたWebアプリケーションです。

**基本的な処理の流れ**

1. ユーザーがブラウザからneck-appにアクセス
2. 必要に応じてGoogleログイン・カメラ・傾きセンサーを設定
3. YouTubeの動画を検索・再生
4. MediaPipeや端末の傾き情報を用いて姿勢・瞬きを検知
5. 判定結果を動画プレイヤーの警告表示に反映
6. 計測データやポイントをCloud Firestoreに保存
7. 保存した記録を取得し、グラフなどで可視化

カメラ映像はブラウザ内で解析し、Firestoreには計測結果を保存します。映像そのものをクラウドへアップロードして解析する構成ではありません。

## 🚀 ローカルでの動かし方

### 必要な環境

- Node.js / npm
- Git
- Google Chromeなどの対応ブラウザ

### セットアップ

リポジトリをクローンして、プロジェクトのディレクトリに移動します。

```bash
git clone https://github.com/yuchi88/Resolve_Teck_neck.git
cd Resolve_Teck_neck
```

依存パッケージをインストールします。

```bash
npm install
```

開発サーバーを起動します。

```bash
npm run dev
```

ブラウザで以下のURLにアクセスします。

http://localhost:5173/

### ビルド

```bash
npm run build
```

ビルド成果物は `dist/` に出力されます。

### Firebase Hostingへのデプロイ

Firebase CLIと対象プロジェクトへの権限がある環境で実行します。

```bash
npm run build
firebase deploy --only hosting --project resolve-teck-neck
```

※ Firebaseの設定値やYouTube APIキー、OAuth設定などは、各自の開発環境に応じて別途設定が必要です。認証情報や秘密情報をリポジトリに直接コミットしないでください。

## 👥 チーム開発の方針

本プロジェクトは4人チームで開発しています。

コンフリクトを減らすため、`src/features/` 以下を中心に機能単位でコードを分割しています。

## ⚠️ 開発上の注意事項

### 1. Google Cloud / Firebaseの利用

本プロジェクトではFirebase Hosting・Authentication・FirestoreなどのGoogle技術を利用しています。

外部サービスの追加やクラウド構成の変更を行う場合は、ハッカソンの規定やチームの開発方針を確認してください。

### 2. カメラ映像の取り扱い

MediaPipeによる解析はクライアントサイドで実行します。

カメラ映像そのものをFirestoreへ保存したり、継続的に外部サーバーへ送信してAI解析したりする構成にはしません。

### 3. ブラウザ・OSの制約

Webアプリでは、OSやブラウザの権限制約により、他のアプリの利用中に継続してカメラやセンサーを利用できるとは限りません。

現在はneck-app内で動画を視聴し、その画面内で姿勢検知と警告を行う構成です。

### 4. 検知結果について

姿勢や瞬きの判定結果は、端末の性能、撮影環境、カメラの位置、利用者の姿勢などによって変動する可能性があります。

本アプリは健康習慣の意識づけを目的としており、医学的な診断を行うものではありません。

# 📱 neck-app

**🌐 公開URL (Firebase Hosting):** https://resolve-teck-neck.web.app/

つい下を向いてしまう若者の「スマホ首（テキストネック）」を、MediaPipeによる骨格推定とゲーミフィケーションで解決するWebアプリです。

## 🎯 解決する課題
- **対象**: 長時間スマホやPCを不適切な姿勢で見てしまう学生・若者
- **課題**: 姿勢の悪化による健康被害（肩こり、頭痛、ストレートネック）
- **アプローチ**: アプリ内で動画を見ている最中の姿勢を監視し、首が前に出ると警告。姿勢を正して「待つ・耐える」ことでリワードが得られる仕組み（セロトニン的体験）を提供。

## 🛠 技術スタック & ハッカソン要件
本プロジェクトは、DevFest Hackathon 2026の規定に基づき、以下の技術を利用して開発・デプロイを行います。

### 必須要件（Google Cloud / Firebase）
- **ホスティング**: Firebase App Hosting (または Firebase Hosting)
- **データベース**: Cloud Firestore (姿勢データの記録・リワード管理)
- **認証**: Firebase Authentication

### フロントエンド・AI
- React (TypeScript) + Vite
- MediaPipe Pose (ブラウザ側でのリアルタイム骨格推定・軽量化のためクライアントサイドで実行)

## ⚠️ チーム開発における禁止事項・注意事項
ハッカソンのルールおよび開発方針を守るため、以下の点に注意してください。

1. **他社クラウド/PaaSの使用禁止**
   - Vercel, Netlify, AWS, Render等の使用は禁止です。必ずFirebase/Google Cloudを使用してください。
2. **重いバックエンド処理の禁止（コスト制限対策）**
   - 本ハッカソンのGoogle Cloudクレジット上限（$20）を超えないよう、動画や画像の常時アップロードによるサーバー側でのAI解析は行いません。AI処理（MediaPipe）は必ずユーザーのブラウザ（クライアントサイド）で完結させてください。
3. **OSのバックグラウンド制限の回避**
   - iOS/Webの制限により、他のアプリの裏でカメラやジャイロを動かし続けることはできません。必ず「本アプリ内」で完結するデモ（アプリ内でYouTubeを再生し、その上で警告を出す等）として実装します。

## 🚀 ローカルでの動かし方
1. `npm install`
2. `npm run dev`
3. `http://localhost:5173/` にアクセス

## 📂 ディレクトリ構成（コンフリクト防止用の機能別分割）
チーム開発でコンフリクトが起きないよう、`src/features/` 以下に機能単位でフォルダ（`.tsx` と専用 `.css`）を分離しています。各機能を改修する際は該当フォルダ内のファイルのみを編集してください。

```text
src/
├── types/
│   └── app.ts                     # 各機能間でやり取りする共通の型（Props）定義
├── features/
│   ├── pose/                      # 📷 メディアパイプ（カメラ骨格推定）
│   ├── tilt/                      # 📱 スマホの傾き検知（ジャイロ・加速度）
│   ├── player/                    # ▶️ YouTube動画プレイヤー
│   ├── warning/                   # ⚠️ 警告バナー（トースト・警告演出）
│   ├── reward/                    # 🏆 リワード（姿勢維持タイマー・ポイント）
│   ├── header/                    # 🧭 ヘッダー・操作バー（URL入力・テストボタン）
│   └── firebase/                  # 🔥 Firebase（認証・Firestore保存）
├── App.tsx                        # 各機能コンポーネントの結合のみ
└── App.css                        # 画面全体の大枠レイアウトのみ
```
